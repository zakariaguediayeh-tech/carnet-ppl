# Carnet PPL — Suivi d'entraînement PPL 6 mois

Tracker d'entraînement PPL (Push/Pull/Legs) progressif avec:
- Saisie des séries en kg × reps
- Rappel de surcharge progressive
- Suivi des 72 séances (6 mois × 4 semaines)
- Statistiques de volume
- Sauvegarde automatique hors-ligne

## Déployer sur GitHub Pages

1. Crée un repo vide sur github.com/new (nom: `carnet-ppl`)
2. Clone-le : `git clone https://github.com/TON_USER/carnet-ppl`
3. Copie tous les fichiers du dossier `ppl-github` dedans
4. `git add . && git commit -m "init ppl" && git push`
5. Va dans Settings → Pages → Source: main branch → Save
6. Attends 30 sec, ton URL est: `https://TON_USER.github.io/carnet-ppl`
7. Copie cette URL et colle-la dans PWABuilder

## Ou utiliser directement le fichier HTML

Télécharge `CarnetPPL.html`, ouvre-le dans Chrome, puis:
Menu ⋮ → Ajouter à l'écran d'accueil
